# Sales Analysis in Microsoft Excel

## Project Overview

This project demonstrates data cleaning, data analysis, and dashboard creation using Microsoft Excel. The Superstore dataset was cleaned, organized, and analyzed through Pivot Tables, lookup functions, calculated fields, and interactive visualizations to provide meaningful business insights.

## Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Lookup Functions (XLOOKUP)
- IF, IFS, SUMIFS, COUNTIFS

---

## Dataset

The project uses the Superstore dataset consisting of the following worksheets:

- Orders
- Products
- People
- Returns

The workbook also includes:

- Pivot Tables
- Dashboard

---

## Key Features

- Data cleaning and formatting
- Duplicate removal
- Data validation
- Pivot Table analysis
- Lookup functions (XLOOKUP)
- Calculated fields using Excel formulas
- Sales performance dashboard
- Multiple chart visualizations
